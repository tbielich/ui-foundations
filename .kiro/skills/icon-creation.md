# Skill: Icon Creation

Create missing SVG icons for the UI Foundations icon set.

Full guide: `docs/agentic/icon-creation.md`

This skill activates the agent-agnostic icon creation guide which covers:
- Canvas and stroke rules (24×24, stroke `#9747FF`, round caps/joins)
- Four keyshapes: circle, square, rect-landscape, rect-portrait
- Naming convention: `<object>[-<variant>][-<modifier>].svg`
- Unicode emoji reference for shape and naming
- Composition rules and pre-creation checklist

Refer to `docs/agentic/icon-creation.md` for the complete specification.
