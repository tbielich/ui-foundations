# Site Data Files

Eleventy data files in `site/_data/` provide build-time data to templates.
Each file exports a function that returns the data object.

## Files

| File | Returns | Used by |
|------|---------|---------|
| `site.json` | `{ baseUrl }` — site URL for SEO/links | All templates via `site.baseUrl` |
| `iconNames.js` | `{ names, withNone, count, sourceDir }` — SVG icon list from `src/assets/icons/` | Playground select controls, icon docs |
| `figmaConnections.js` | `{ componentNames, byName, urlsByName, sourceDir }` — Code Connect links parsed from `schemas/web-*.figma.ts` | Component doc pages (Figma links) |
| `tokensTable.js` | `{ rows, count, scopes, kinds, sourceDir }` — flat token list from `dist/tokens/tokens.yaml` | Token explorer page |
| `colorDocs.js` | `{ groups, sourceDir }` — color tokens grouped by brand/mode/core | Color documentation page |

## How They Work

All token-related data files depend on `dist/tokens/tokens.yaml` which is
generated by `npm run tokens:generate`. The data is only fresh after a build.

```
figma/exports/ → tokens:generate → dist/tokens/tokens.yaml
                                        ↓
                              site/_data/tokensTable.js
                              site/_data/colorDocs.js
```

Icon and Figma data read directly from source:

```
src/assets/icons/*.svg → site/_data/iconNames.js
schemas/web-*.figma.ts → site/_data/figmaConnections.js
```

## Shared Library

`site/lib/tokens-yaml.js` provides:
- `TOKENS_YAML_RELATIVE_PATH` — path constant
- `loadTokensFromYaml()` — parses `dist/tokens/tokens.yaml` into array

Used by both `tokensTable.js` and `colorDocs.js`.

## Adding a New Data File

1. Create `site/_data/myData.js`
2. Export a function: `module.exports = () => ({ ... })`
3. Access in templates as `{{ myData.property }}`
4. If it depends on generated files, ensure `build:all` runs first

## `componentTokenTable` Shortcode

Defined in `site/lib/component-token-table.js` and registered in
`.eleventy.js`. Used in playground pages to render token usage tables from
a CSS file path.

Usage in templates:
```njk
{% componentTokenTable "src/ui/patterns/button.css" %}
```
